# Розподілена система візуалізації фракталів з балансуванням навантаження (.NET 8)

Навчальний проєкт реалізації розподіленої відмовостійкої системи для виконання ресурсомістких математичних обчислень (множини Мандельброта та Жюліа) на платформі **C# 12 / .NET 8 (LTS)**.

---

## 🚀 Швидкий старт (Quickstart)

Для повного розгортання всього комплексу контейнерів достатньо виконати:

```bash
# 1. Склонувати або перейти в каталог проєкту
cd C:\web

# 2. Запустити весь комплекс через Docker Compose (v2)
docker compose up --build -d

# 3. Перевірити працездатність усіх сервісів
docker compose ps
```

Після запуску відкрийте браузер за адресою: **[https://localhost](https://localhost)**

## 🌐 Посилання та маршрути системи

| Сервіс / Сторінка | URL | Опис |
| :--- | :--- | :--- |
| **Веб-інтерфейс (SPA)** | `https://localhost` | Інтерактивний візуалізатор фракталів із прогресивним рендером на Canvas, SSE оновленням та історією |

| **Health Check Liveness** | `https://localhost/api/healthz` | Перевірка працездатності екземплярів Web API |
| **Health Check Readiness** | `https://localhost/api/readyz` | Перевірка готовності зв'язку з PostgreSQL |

## 🔒 Довіра до самопідписаного SSL-сертифіката

При першому старті контейнер `init-certs` автоматично генерує валідний самопідписаний сертифікат RSA 2048.

- **У браузері (Chrome / Edge / Firefox)**: при першому переході на `https://localhost` натисніть **«Додатково»** -> **«Перейти на localhost (небезпечно)»**.
- **У curl**: додайте прапорець `-k` або `--insecure`:

  ```bash
  curl -k https://localhost/api/healthz
  ```

- **Як додати до довірених сертифікатів Windows**:
  1. Скопіювати `cert.pem` із тома Docker або зберегти сертифікат із браузера.
  2. Подвійний клік на сертифікат -> **«Встановити сертифікат»** -> **«Локальний комп'ютер»** -> **«Помістити всі сертифікати в наступне сховище»** -> обрати **«Довірені кореневі центри сертифікації»**.

## 🏗️ Структура рішення

```text
src/
  Fractals.Core/        – математичне ядро, алгоритми рендерингу, палітри, скінченний автомат
  Fractals.Data/        – EF Core DbContext, сутності tasks/users/scaling, атомарний claim (SKIP LOCKED)
  Fractals.Api/         – Web-шар (Minimal API / Controllers, JWT/Cookie auth, SSE, X-Served-By, Admin API)
  Fractals.AppServer/   – Worker Service (захоплення задач із БД, обчислення смугами, watchdog, heartbeat)
  Fractals.Autoscaler/  – демон горизонтального автомасштабування на базі Docker.DotNet
tests/
  Fractals.UnitTests/   – модульні тести математики, лімітів, автомату станів та репозиторію
  Fractals.IntegrationTests/ – інтеграційні тести API, авторизації, IDOR та балансування
frontend/               – клієнтська частина (HTML5 Canvas, CSS, ES Modules)
nginx/                  – конфігурація зворотного проксі-сервера (least_conn, SSL, SSE)
docs/                   – повний комплект архітектурної документації для захисту
scripts/                – демонстраційні скрипти балансування
loadtest/               – сценарії навантажувального тестування k6
```

## 🧪 Запуск тестів та форматування

```bash
dotnet test Fractals.slnx

dotnet format --verify-no-changes
```
